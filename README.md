# ANN Lab Task 1 — Linear Regression

## Objective

Implement Linear Regression on two different regression datasets and develop user interfaces using Gradio and Flask.

## Datasets

1. Medical Insurance Cost Dataset — Predict medical insurance charges.
2. California Housing Dataset — Predict median housing values.

## Technologies Used

* Python
* Google Colab
* Pandas and NumPy
* Scikit-learn
* Matplotlib
* Gradio
* Flask
* Pyngrok

## Implementation

1. Dataset loading and exploration
2. Data preprocessing
3. Train-test splitting (80/20)
4. Linear Regression model training
5. Model evaluation using MAE, MSE, RMSE and R²
6. Actual vs. Predicted visualizations
7. Gradio and Flask prediction interfaces

## How to Run

1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Install the required libraries when prompted.
4. Launch the Gradio interface.
5. For Flask, configure your own ngrok authtoken in Colab Secrets under `NGROK_AUTH_TOKEN` and run the Flask cells.
